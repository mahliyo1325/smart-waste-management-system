# Aqlli chiqindilarni qayta ishlash tizimi (Smart Waste Management System)

Ushbu loyiha chiqindilarni qayta ishlash statistikasi va aqlli konteynerlar telemetriyasi asosida tejalgan energiyani hisoblash, anomaliyalarni aniqlash hamda chiqindi yig'ish jarayonini optimallashtirish uchun ishlab chiqilgan.

## Loyiha tuzilishi
- `src/main.py` — FastAPI asosidagi backend REST API (tizim holati va tejalgan energiyani hisoblash endpointlari).
- `docs/schema.sql` — PostgreSQL ma'lumotlar ombori sxemasi (`waste_categories`, `annual_waste_records`, `smart_bins`, `bin_telemetry_logs`).
- `requirements.txt` — Loyiha uchun zarur Python kutubxonalari.
